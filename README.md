# ラリーノート

ソフトテニス選手が、練習中・試合中に技術の成功率、ポイントの内訳、戦術の自己評価、メンタル（集中力・緊張度・役割の明確さ・呼吸・自信）を記録し、推移を振り返るためのWebアプリです。

- 公開アドレス: https://seagullpark-crypto.github.io/rally-note/
- スマホでは「ホーム画面に追加」でアプリとしてインストールできます。電波がなくても動きます。
- 記録は各自のスマホの中（ブラウザの保存領域）にだけ保存され、このリポジトリやサーバーには送られません。
- 選手は「振り返り」タブの「監督に送る」でファイルを書き出し、監督は「監督」タブでそのファイルを読み込みます。

## 更新するとき

`index.html` などを変えたら、`sw.js` の `VERSION` を1つ上げてください。スマホ側が新しい版に入れ替わります。
